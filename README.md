# Terminal desktop cycle (macOS)

If `run` cannot find its configuration file, it opens the setup wizard automatically, saves your answers, and starts automation. At the application prompt, submit an empty line to finish the list; Ctrl+C cancels setup without saving.

Run from this directory:

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 desktop_cycle.py setup
python3 desktop_cycle.py check
python3 desktop_cycle.py run
```

Setup prompts for application names (one per line), idle delay before resuming after manual input (default 30 seconds), minimum and maximum application switching intervals (default 5–10 seconds), action interval, pointer movement, and an optional Shift tap. It saves `desktop_cycle.json` beside the script. Each switch gets a fresh random delay within the configured range. Older configurations with `switch_seconds` automatically use the new 5–10-second defaults. Run setup again to change settings, or edit the JSON fields `switch_min_seconds` and `switch_max_seconds`. Use `--config /path/to/settings.json` after any command for a separate configuration.

Enable Accessibility and Input Monitoring for the terminal/Python host under **System Settings > Privacy & Security** when needed; restart the terminal afterward. `check` validates and displays configuration without activating applications. Application names are resolved before `run` starts.

Setup offers startup mode **1 — start immediately** (default) or **2 — wait for idle time** (default 30 seconds). The choice is saved as `start_immediately`; older configurations default to immediate startup. Immediate startup occurs after startup checks unless new manual input is detected. After any observed input not generated by this script, it waits for the full idle delay before resuming. It switches through configured apps, moves the pointer smoothly to random positions on the main screen if enabled (up to 1.5 seconds per movement, at the configured action interval), and optionally taps Shift. It does not enter text or click. Shift may still interact with app shortcuts and accessibility settings. Input pauses subsequent actions; an activation or input event already dispatched cannot be undone, so takeover is not instantaneous. If event monitoring is disabled, the script exits. Ctrl+C stops it.

There is no separate window, menu-bar icon, background service, or automatic startup. The terminal must remain running. The process remains visible to macOS and monitoring software; there is no guarantee of concealment or how a tracker classifies its activity. The script does not alter screenshots or tracker records. It observes input event timing but does not save typed keys or screenshots.

The implementation uses [PyObjC's Quartz bindings](https://pyobjc.readthedocs.io/en/latest/apinotes/Quartz.html) and tags its own events using [Core Graphics event source user data](https://developer.apple.com/documentation/coregraphics/cgeventfield).
